# Pixelmorph

![Pixelmorph cover](assets/readme-cover.svg)

A focused Python project from Mert Efe Kurt.

`Python`

## Start here

```bash
git clone https://github.com/mertefekurt/pixelmorph.git
cd pixelmorph
python -m pip install -r requirements.txt
python main.py
```
